# LiftWork

LiftWork é uma aplicação para acompanhamento de treinos, criada para facilitar a organização e o registro da sua evolução na academia.

O projeto ainda está em desenvolvimento e, no momento, não há previsão para o lançamento de uma versão MVP.

## Por que o LiftWork?

Cansou de tentar lembrar de cabeça ou anotar em lugares desorganizados, como WhatsApp ou bloco de notas, quais exercícios fez, quais cargas utilizou, quantas repetições conseguiu ou qual foi o RIR de cada série?

O LiftWork vem para centralizar essas informações em um só lugar, facilitando o acompanhamento dos seus treinos e da sua evolução ao longo do tempo.

## Funcionalidades

* Gerenciamento de exercícios
* Criação e organização de rotinas
* Execução de treinos
* Registro de cargas, repetições e séries realizadas
* Acompanhamento de RIR
* Histórico de treinos
* Acompanhamento de progresso
